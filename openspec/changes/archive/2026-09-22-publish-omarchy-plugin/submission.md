### Maintainer notes

Service plus bar widget, id `io.github.zakkoo.proton-drive`. `omarchy plugin add` copies the shell files. The Node engine is built only when the user runs `scripts/install-engine`. That command uses no sudo and does not pipe a download into a shell. An optional `--service` flag writes a user unit only when one is not already there, and starts `proton-drive-sync run --no-tray`. Removal does not delete the sync folder, the Proton session, or the tool's config.

The preview (`preview.jpg`) was designed by the author for this listing.
